## Как работать с проектом

### Установка пакетов

```
npm i
```

### Сборка проекта

#### Сборка для разработки

```
npm run dev
```

#### Сборка для прода

```
npm run build
```

#### Очистка сборки

```
npm run clear
```

### Запуск локального сервера

При запуске локального сервера собирается сборка для разработки.

```
npm run start
```

### Работа с линтерами

### Запуск проверки eslint

```
npm run lint
```

Запуск проверки eslint с флагом --fix(исправит ошибки если возможно)

```
npm run lint:fix
```

### Работа с тестами

```
npm run jest
```
